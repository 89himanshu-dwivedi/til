# 11. Know Data Ethics, Privacy, and Practical Implementation

## Key Concepts

### Ethical Issues in Data Collection and Analysis

Important ethical concerns include:

- **Privacy violations**
  - Collecting/analyzing personal information without consent.
  - Using personal information for purposes other than the original purpose.

- **Data breaches**
  - Unauthorized access to or release of sensitive data.
  - Can cause financial or reputational harm.

- **Bias**
  - Systematic errors or inaccuracies in data, algorithms, or decision-making.
  - Can cause unfair or discriminatory outcomes.

### Data Privacy, Consent, and Confidentiality

Important strategies include:

- **Encryption**
  - Protects sensitive data so only authorized users can access it.

- **Anonymization**
  - Removes personally identifiable information so data cannot easily be linked to specific individuals.

- **Access controls**
  - Restrict sensitive data to authorized users.
  - Ensure data is used only for its intended purpose.

### Addressing Bias and Fairness

Strategies include:

1. **Diversifying data sources**
2. **Improving data quality**
3. **Conducting bias audits**
4. **Incorporating fairness metrics**
5. **Promoting transparency**

### Legal and Regulatory Frameworks

Important frameworks covered:

- **CCPA**
  - Applies to companies doing business in California that collect personal data of California residents.

- **HIPAA**
  - Applies to healthcare organizations and governs protected health information in the United States.

- **GDPR**
  - Applies to organizations processing personal data of European Union residents.

- **EU AI Act**
  - Comprehensive AI regulations, including bans on unacceptable-risk systems and legal requirements for high-risk applications.

### Data Lifecycle Management Best Practices

- Data governance policies
- Regular audits and assessments
- Accurate, complete, representative data
- Secure storage
- Authorized access
- Use data only for intended purposes
- Responsible data sharing
- Appropriate safeguards
- Data retention policies
- Secure deletion when data is no longer needed

### Einstein Trust Layer

The **Einstein Trust Layer** is a secure AI architecture built into the Salesforce platform.

It uses agreements, security technology, and data/privacy controls to help keep company data safe while using generative AI.

Examples of capabilities mentioned:

- Masking sensitive data
- Merging relevant record data with prompts for more accurate results
- Security and privacy controls
- Trust-focused AI architecture

# 13. Get to Know Autonomous Agents

## What Is an Autonomous Agent?

An autonomous AI agent:

- Understands and responds to requests.
- Can act without direct human intervention.
- Receives a goal and generates tasks for itself.
- Completes tasks and continues until the goal is achieved.
- Works in dynamic environments.
- Can be used in customer service, marketing, commerce, sales, and other areas.

Unlike traditional chatbots, autonomous agents are not limited to predefined rules.

## Four Key Components

### 1. Data
Data is the foundation of an autonomous agent's functionality.

It enables the agent to:
- Make informed decisions
- Execute tasks autonomously
- Personalize experiences

### 2. Decision-Making
Agents analyze data and use decision-making algorithms to prioritize and execute tasks efficiently.

### 3. Action Execution
After deciding what to do, the agent executes planned actions such as:
- Reserving rooms
- Arranging transportation
- Performing business tasks

### 4. Learning and Adaptation
Agents learn from interactions, feedback, and outcomes to improve future performance.

## Industry Examples

- Approve care requests

### Financial Services

- Escalate final authorization to humans

### Insurance
Agents can:
- Update coverage

- Issue claims checks
- Renew policies
- Draft communications

### Retail

- Analyze preferences

# 16. Get to Know Reasoning Engines

## What Is a Reasoning Engine?

A reasoning engine is a type of AI that:
- Gathers information
- Follows logical rules
- Makes decisions
- Helps solve complex problems

## Three Types of Reasoning

### Deduction
Starts with a general rule and applies it to a specific case.

Example:
- All fruits have seeds.
- A mango is a fruit.
- Therefore, a mango has seeds.

### Induction
Uses patterns from past experience to make a general prediction.

Example:
- The last five meetings started late.
- The next meeting will probably start late.

### Abduction
Makes the best guess from limited clues.

Example:
- The lights are off and nobody answers.
- They are probably not home.

## Four LLM Reasoning Strategies

### 1. Chain-of-Thought (CoT)
- Breaks a difficult problem into smaller steps.
- Useful for math, common-sense reasoning, and logical tasks.

### 2. Reasoning and Acting (ReAct)
- Combines reasoning with actions.
- Interacts with information.
- Checks results.
- Uses feedback.
- Can reduce hallucinations.

### 3. Tree of Thoughts (ToT)
- Explores multiple possible reasoning paths.
- Useful for complex problems, strategic decisions, creative tasks, and puzzles.

### 4. Reasoning via Planning (RAP)
- Simulates future outcomes.
- Predicts how actions may play out.
- Explores alternatives.
- Refines plans.
- Useful for long-term planning and multi-step problem solving.

## Agentforce and LLM Reasoning

The process described:

1. User provides a request.
2. Agentforce sends it to a secure LLM with a carefully designed prompt.
3. The LLM translates the request into a defined need.
4. Another prompt asks the LLM to create a plan.
5. The LLM creates step-by-step actions using only allowed agent actions.
6. The agent executes the steps in the correct order.
7. The result is delivered to the user.

## Quiz Answers

1. **B — It reduces "hallucinations" by interacting and using feedback to check its answers.**
2. **A — The agent translates the input into a detailed prompt, uses that prompt to create executable steps, and then follows those steps.**

# 17. Discover the Atlas Reasoning Engine

## What Is Atlas?

The **Atlas Reasoning Engine** is the "brain" behind Agentforce and is part of Salesforce's agentic layer.

It is designed to simulate human-like thinking and planning and uses techniques including advanced **Retrieval Augmented Generation (RAG)**.

Atlas helps AI agents:
- Analyze information
- Determine appropriate actions
- Follow instructions
- Proactively plan toward goals

## Four Key Atlas Concepts

### 1. Reason–Act–Observe Loop (ReAct)
Atlas:
1. Reasons about a step.
2. Takes an action.
3. Observes the outcome.
4. Repeats until the goal is completed.
5. Can ask for clarification when needed.

### 2. Subagent Classification
Every request is mapped to a **subagent**.

The subagent defines:
- The AI's job for that request
- Valid actions
- Applicable policies

### 3. Richer Conversations
Atlas supports:
- Natural-language responses
- Follow-up questions
- Past conversational context

This creates smoother, more human-like interactions.

### 4. Visible Reasoning
Atlas shares its "thoughts" and explains why it acted a certain way.

This helps admins:
- Review decisions
- Prevent errors
- Build trust

These insights can be accessed in Agentforce Builder.

## Three Key Atlas Capabilities

### Proactive Actions
Agents can trigger actions when:
- CRM data changes
- An email arrives
- A meeting is upcoming

### Dynamic Information Retrieval
Atlas retrieves relevant:
- Structured data
- Unstructured data
- Salesforce Data 360 information
- Web information
- Internal documents

### Seamless Human Handoff
If Atlas encounters:
- A difficult question
- A strict business rule
- A situation requiring human judgment

It can hand the conversation to a human.

## Important Atlas Idea

Atlas is **goal-oriented**.

It does not simply respond to prompts. It works toward successful outcomes even when the path is not linear.
